## 工程代码分析（只读，无改动）

用户要求分析 mobile-automation 工程，不做任何改动。

### 项目概述
- Python + ADB 的 Android 自动化工具，面向内部使用
- 核心能力：设备发现、UI 操作、JSON 任务编排、截图/dump UI
- 业务场景：青书 App (Poppo) 用户采集、私信自动化、Play Ocean Hunt 游戏自动点击、ADB SSH 隧道监控

### 代码规模
- src/ 10 个模块，3168 行
- examples/ 8 个脚本，1463 行
- tests/ 12 个测试文件，3126 行（测试与源码比例约 1:1）
- 依赖仅 Pillow，无其他第三方库

### 架构分层
1. adb.py — ADB 封装（设备管理、输入法、tap/swipe/input/screenshot/dump_ui/重连）
2. ui.py — UI 树解析（Bounds/UiNode/UiTree，XPath 查找、中心候选、安全点击）
3. runner.py — JSON 声明式任务执行器
4. cli.py — 命令行入口（devices/run/screenshot 子命令）
5. square.py — 青书 Square 页用户采集（页面分类、恢复、断点续跑、性别识别、CSV schema 迁移）
6. messaging.py — Poppo 私信工作流（精确搜索、在线检查、首发确认、回复核对、批量轮次）
7. outreach.py — 用户筛选与私信计划生成
8. feishu.py — 飞书自定义机器人通知
9. examples/ — 8 个独立脚本入口

### 设计亮点
- 无第三方依赖（仅 Pillow），ADB 命令直接 subprocess 调用
- 断点续跑 + CSV schema 自动迁移
- 设备离线自动重连（递增等待，飞书通知）
- 输入法安全切换（UnicodeIME for 非 ASCII 文本，用完恢复）
- CSV 注入防护（_csv_safe 对 =/+/-/@ 开头加单引号前缀）
- 多语言模板（40+ 语言，按国家路由）
- 异常恢复链：详情页返回 → 首页重新导航 → 强制重启 App
- 测试覆盖率高，1:1 测试代码比
